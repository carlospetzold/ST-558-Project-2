Introduction

Here we are working on our second project for ST 558, back to the old grindstone… We will work on building a shiny app to allow a user to explore a data set of our choosing.

For this project, I decided to use player-level data from the 2025-2026 UEFA Champions League (UCL) season (highest level of professional soccer) to build my app (Source: FotMob). The criteria for a player being included in the data set is that they had to make at least 1 appearance (as either a starter or a substitute) in the UCL season at any point.

We are pulling in 2 separate data sets below:

  1. Player Matches: This data set contains match-level information from our 2025-26 UCL season for each player that registered at least 1 appearance. This includes information like player rating, minutes played, goals scored, expected goals, etc.

To be honest, these goal and assist numbers don’t look too hot for a Top-Flight German team that is (supposedly) meant to be a top 2 team in Germany, and a top 12 club in Europe. Luckily, our data (and many other sources of soccer data), track player match ratings for each game, which scale from 1-10. In the FotMob rating system, each player starts their appearance with a 6.0 rating, which increases or decreases based on their actions during the game. Let’s take a look at the average match rating across the season for the Dortmund players, and compare them to the other teams:

The distance covered table tells us something interesting: the amount of distance that a team covers during a game does not necessary correlate with team success. The UCL champions, PSG, did have quite a high average distance covered per player per game, but there are other teams that went far in the tournament that were much lower on the list, like Barcelona (dead last in average distance covered!) and Arsenal (middle of the pack). The 3 highest distance-covering teams did not make it past the round of 16, with only 1 even making it there.

The table for chances created is a different story. Chances created translate to goals scored, which translates to games won. This is, in my own personal opinion, the best proxy for whether or not a team will be successful. PSG, the eventual winners, had the highest average number of chances created per player per game, with Bayern in 3rd and Arsenal just behind both in 8th. Athletico Madrid again here showing that they over performed, having the 16th highest number of chances created per player per game.

Looking at Dortmund in both cases, they placed 10th in Distance Covered and 19th in Chances Created…lots of running but very little chance creation. Not the best formula for success, and certainly not the best formula for keeping players motivated to win. The last thing any player wants is to be running the entire game with little to no opportunities to put chances away. Hopefully things improve this season, but for now, the running will continue until chance creation improves…

league_heatmap_data <- league_summary |>
  pivot_longer(
    cols = c(
      avg_match_rating,
      avg_distance_covered,
      avg_chances
    ),
    names_to = "Metric",
    values_to = "Value"
  ) |>
  group_by(Metric) |>
  mutate(
    Standardized_Value = if (
      all(is.na(Value)) ||
      is.na(sd(Value, na.rm = TRUE)) ||
      sd(Value, na.rm = TRUE) == 0
    ) {
      NA_real_
    } else {
      as.numeric(scale(Value))
    }
  ) |>
  ungroup() |>
  mutate(
    Metric = recode(
      Metric,
      avg_match_rating = "Average Match Rating",
      avg_distance_covered = "Average Distance Covered",
      avg_chances = "Average Chances Created"
    )
  )

team_order <- league_summary |>
  arrange(avg_match_rating) |>
  pull(team_name)

league_heatmap_plot <- league_heatmap_data |>
  ggplot(aes(
    x = Metric,
    y = factor(team_name, levels = team_order),
    fill = Standardized_Value
)) +
  geom_tile(color = "white") +
  scale_fill_gradient2(
    low = "#555555",
    mid = "white",
    high = "#FDE100",
    midpoint = 0,
    na.value = "gray90"
  ) +
  labs(
    title = "Team Performance Across Key Metrics",
    subtitle = "2025-26 UEFA Champions League",
    x = "Performance Metric",
    y = "Team",
    fill = "Standardized\nValue"
  ) +
  theme_minimal() +
  theme(
    plot.title = element_text(face = "bold"),
    axis.text.x = element_text(angle = 30, hjust = 1),
    panel.grid = element_blank()
  )
